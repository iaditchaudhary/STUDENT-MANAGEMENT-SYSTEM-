# Student Management System

## Description
This is a Java console-based application designed to manage student records efficiently. It supports essential CRUD operations: adding, viewing, searching, updating, and deleting student details like roll number, name, course, semester, and CGPA. The project demonstrates key Java concepts such as object-oriented programming, collections, and user interaction through a menu-driven interface.

## Features
- Add new student records with detailed information.
- View all stored student records.
- Search for a student by roll number.
- Update existing student information.
- Delete student records.
- Simple analytics like finding average CGPA and topper student.

## Technologies Used
- Java (Core)
- Console-based UI
- ArrayList for data storage and management

## How to Run
1. Compile the `StudentManagementApp.java` file.
2. Run the compiled class from the command line or your preferred Java IDE.
3. Use the console menu to perform operations on student records.
